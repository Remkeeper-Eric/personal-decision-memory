# 安装与配置

本版以 Windows、Python 3.12 和源码可编辑安装为验证目标。macOS/Linux 的核心命令可能可用，但 PowerShell 启停脚本和完整工作流未在这些平台验收，不宣称开箱即用。

## 先确认源码能运行

所有命令在包含 pyproject.toml 的仓库根目录执行，默认库是该目录的 vault/。完整顺序见 [README](../README.md)。安装后运行：

```powershell
.\.venv\Scripts\python.exe -m decision_memory doctor
```

doctor 应返回 ok=true。对于新库，active_count=0 是预期状态；搜索无匹配仅表示这次查询没有结果，不能代替库状态检查。

requirements.lock.txt 记录本版 Windows 验证用依赖，包含测试依赖。其他平台不要直接套用其中的 pywin32；尚未验证的平台应先隔离试验。源码可编辑安装让 CLI、安装脚本和审核页共享同一目录，请不要安装后随意移动仓库。

## 可选：安装 Codex 集成

```powershell
.\.venv\Scripts\python.exe scripts/install_codex.py
.\.venv\Scripts\python.exe scripts/install_codex.py --apply
```

第一条只预览；第二条写配置，且不会批准任何记忆。安装目标：

- Codex 用户配置目录中的 AGENTS.md：只更新标记为本系统管理的区块。
- 同目录的 config.toml：只更新 personal-decision-memory MCP 表和其子表，保留其他设置。
- 用户的 .agents/skills/：安装 decision-context 和 review-personal-decision，所有权标记用于防止覆盖手工改动。
- runtime/install-backups/：保存被修改文件的原始内容；runtime/tmp/：提供已存在的 MCP 临时目录。

默认 Codex 配置目录来自 CODEX_HOME，未设置时为用户目录下 .codex；Skills 默认在用户目录的 .agents/skills。仓库中的模板不包含作者的真实路径，安装时按你电脑的位置生成。

官方配置依据：[MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)、[用户级 Skills](https://learn.chatgpt.com/docs/build-skills)、[AGENTS.md 指引](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。不同版本的客户端设置页可能不同，实际工具调用才说明当前连接可用。

## 自定义目录

安装脚本支持 --codex-home、--skills-home、--vault 和 --backup-root。先预览，例如：

```powershell
.\.venv\Scripts\python.exe scripts/install_codex.py --codex-home runtime/test-profile --skills-home runtime/test-skills --vault runtime/test-vault --backup-root runtime/test-backups
```

这条命令只展示一个隔离配置示例，未安装，也未初始化该库。真实使用自定义库时，应先用相同 --vault 参数运行 init，再保持 MCP、全局指引、审核命令和备份目标一致。

本地 CLI 的 --vault 是全局参数，必须放在子命令之前：

```powershell
.\.venv\Scripts\python.exe -m decision_memory --vault runtime/test-vault init
.\.venv\Scripts\python.exe -m decision_memory --vault runtime/test-vault doctor
.\.venv\Scripts\python.exe -m decision_memory --vault runtime/test-vault review --session-file runtime/test-review-session.json
```

自定义库请使用这类显式命令；两个 PowerShell 辅助脚本只管理默认 vault/。前台 review 用 Ctrl+C 停止，不要把演示库注册成日常中央库。

## 连接确认与故障区分

重载 MCP 或重新打开 Codex，在新会话实际调用 search_memory/build_context。应区分：工具没加载、服务启动失败、查询无匹配、正文指纹失效。不要把任何一种失败说成“已经学习”。如果 CLI 可用，可用 codex mcp get personal-decision-memory 检查注册；此命令不等于当前会话已经成功调用。

MCP 只提供 search_memory、get_memory、build_context。候选只能在用户明确要求时生成；批准由本机审核页完成，Agent 不应调用发布接口或替用户点击确认。

## 移动、更新与移除

升级前备份个人库及需要保留的草稿，阅读 [CHANGELOG](../CHANGELOG.md)。仓库移动后，原虚拟环境可能不再有效，应重建环境、预览安装变更并重新指向新位置；如果安装器报告同名入口指向其他程序，不要强行覆盖，应先核实旧注册。

同名 Skill 若不属于本系统，或者有人工修改，安装器会停止。应比较内容和备份后由使用者决定，不删除别人的 Skill 来绕过保护。

移除集成时，只移除 config.toml 中本系统的服务器表、AGENTS.md 的受管区块和带本项目所有权标记的两个 Skill。不要用旧配置备份整体覆盖后来新增的配置。个人库与历史备份不会因为移除入口而自动删除。

完整配置和安装备份可能含其他服务器的凭据，请只在本机保存，不要贴到公开 issue。
