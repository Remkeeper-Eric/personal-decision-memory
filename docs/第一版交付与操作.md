# 第一版交付与操作

此文档基于 0.1.0 整理，审核流程已改为对话内批准。作者开发期的机器状态、全局配置备份和个人库不随仓库分发。

## 使用入口

1. 在仓库根目录按 [README](../README.md) 安装 Python 环境并运行 init。
2. 如需 Codex 集成，先运行安装预览，再由你选择是否 --apply；安装后用新会话实际调用 MCP。
3. Obsidian 可选，打开本仓库的 vault/，不必常驻。
4. 明确要求反思后先讨论，Codex 在对话中展示完整版本；你明确批准这版并要求记录后才保存，无需打开页面。单独要求草稿时，草稿不参与正式检索。
5. 后续任务核对实际记录 ID、版本和条件，检查它是否影响了判断。一次引用不能证明长期个人化成功。

本地 preview/approve/revoke 命令由 Codex 按实际用户授权执行，指纹、库 ID 与版本不匹配时停止。旧审核页仅兼容保留，不作为默认步骤；参见 [安装与配置](安装与配置.md)。

## 测试证据的含义

最早开发阶段有 44 项工程测试，随后增加检索修复与边界覆盖；修复后曾通过 100 项。发布整理又补充安装和打包检查，当前数量以你本机运行 pytest 的输出为准。

开发期的 verification/、testing/runs/ 是本地原始证据，不包含在源码发布包中。公开摘要见 [应用边界测试结果](应用边界测试结果-2026-10-15.md) 和 [检索同义表达修复说明](检索同义表达修复说明-2026-10-15.md)。这些摘要描述当时的实验，不是对新用户环境的测试承诺。

## 边界

本项目实现外部记忆检索和人工审核，不进行模型权重训练。不自动扫描旧聊天、不自动反思、不自动批准。有限同义词与字面匹配可能漏掉低文字重叠表达；大规模性能、主动检索触发与真实决策改善仍需验证。

有关未决问题的重新检查条件见 [待真实使用验证的问题](待真实使用验证的问题.md)。
